## Built with

Vite · Three.js (3D scene) · GSAP (animation) · Lenis (smooth scrolling) · HTML / CSS / JavaScript

## Run it locally

```bash
git clone https://github.com/Ganesh-pixel-dev/Ganesh-Portfolio.git
cd Ganesh-Portfolio
npm install
npm run dev
```

Build for hosting with `npm run build` (output in `dist/`).
